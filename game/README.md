# game — ゲーム本体

**作者（るねつき）の許諾を得て同梱しています。**

| フォルダ | 中身 | いつ使うか |
|---|---|---|
| `LvK/` | 作者からいただいたそのままのビルド | **ふだん遊ぶとき**（1人プレイ・ローカル対戦） |
| `LvK_online/` | `LvK/` に `LvKPatch` を当てたもの | **オンライン対戦のとき** |

## どちらを使うか

**オンラインで遊ぶなら `LvK_online/` です。**

```
LvK_online\RPG_RT.exe
```

`LvK_online` は **同期クライアントを動かしていないとキーがまったく効きません。**
入力が全部ネットワーク経由になるためです。オフラインで遊びたいときは
`LvK/` のほうを起動してください。

## このビルドについて

- 起動するとすぐにマルチプレイのキャラ選択に入ります（タイトル画面はありません）
- キャラ選択で `1` を押すと、全員のカーソルが初期化されます
  （選んだキャラは残ります）
- キャラ選択で `Shift` を押すと設定メニュー（プレイヤー数・ライフ・カブ・
  チーム・ステージ）が出ます

遊び方は `LvK/HowtoPlay(English).txt` と `LvK/LvK_Instcard.png` に、
参加者と素材の一覧は `LvK/LvK参加者まとめ.txt` にあります。

## パッチを当て直したいとき

作者から新しいビルドをもらったら、`LvK/` を差し替えて当て直します。

```
LvKPatch\bin\LvKPatch.exe
   ゲームのフォルダ : ...\luneTools\game\LvK
   コピー先         : ...\luneTools\game\LvK_online
   「パッチを当てる」
```

パッチャーは書き換える場所を**オフセットではなく形で探す**ので、
作者がイベントを足してオフセットがずれても、そのまま当たります。
（実際、今回のビルドは LDB が 3343 バイト増えて全部ずれていましたが、
11箇所すべて自動で追従しました）

`LvK_online/RPG_RT.ldb.bak` はパッチを当てる前の控えです。
`LvKPatch` の「元に戻す」で戻せます。

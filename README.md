# luneTools

「るねキャラｖｓカワイコチャンズ」(RPG Maker 2003 / Maniacs Patch) 向けのツール置き場。

`game/LvK_net/` にパッチ済みのゲーム本体を同梱しています（作者の許諾を得たもの）。
手持ちのゲームに自分で当てたい場合は [LvKPatch](LvKPatch/) を使ってください。

## 収録ツール

### [Sync_LvK](Sync_LvK/) — オンライン対戦

**離れた場所にいる人どうしで対戦するためのツール。最大4人。**

はじめての人は **[Sync_LvK/HOWtoUSE.md](Sync_LvK/HOWtoUSE.md)** を読んでください。
パッチ当てからサーバー起動、参加までひととおり書いてあります。

| あなたは | 起動するもの |
|---|---|
| 対戦部屋を立てる（ホスト） | `Sync_LvK/Server/bin/LvKSyncServerGui.exe` |
| 対戦に参加する（プレイヤー） | `Sync_LvK/Client/bin/LvKSyncClientGui.exe` |

サーバーは入力を配るだけで、ゲームには触りません。
誰が何Pに座っているかが一覧で見えます。

ポートは **TCP 47801 の1つだけ**で、開放が必要なのはホストのPCだけです。
プレイヤー側はファイアウォールもルーターも触りません。

画面なしのコマンド版は [legacy/cli](legacy/cli/) へ移しました。
プロトコルが古く、設定メニューの同期などを知りません。**画面つき版を使ってください。**

### [LvKPatch](LvKPatch/) — ゲーム側の下ごしらえ

**オンライン対戦の前に、ゲームへ1回だけ当てるパッチャー。**

ゲームは毎フレーム自分でキーボードを読み直すため、そのままでは外から
入力を渡しても上書きされてしまいます。この読み取りを
「ネットワークから届いた入力を読む」に差し替えます。

フォルダを選んで「調べる」→「パッチを当てる」を押すだけです。
既定では `〜_online` というコピーを作って当てるので、元のフォルダは残ります。

> パッチ済みのビルドは**同期クライアントを動かしていないと
> キャラ選択から先でキーが効きません**。ひとりで遊ぶときは元のフォルダを使ってください。

### [game](game/) — ゲーム本体

**作者の許諾を得て同梱しています。**

| フォルダ | いつ使うか |
|---|---|
| `game/LvK/` | ふだん遊ぶとき（1人プレイ・ローカル対戦） |
| `game/LvK_online/` | オンライン対戦のとき（パッチ済み） |

### [legacy](legacy/) — もう使っていないもの

役目を終えたツールを、消さずに置いてあります。**ふだんは使いません。**

| | 何だったか |
|---|---|
| `legacy/cli/` | 画面なしのコマンド版。プロトコルが古い |
| `legacy/SyncLvK/` | 旧：入力ではなく状態変数を送る方式 |
| `legacy/VPad/` | 仮想ゲームパッド。このゲームは winmm 読みなので効かない |

## ビルド

いずれも .NET Framework 4.x 同梱の `csc.exe` でビルドできる。外部依存なし。
各ツールのフォルダで `build.cmd` を実行する。

# legacy — もう使っていないもの

役目を終えたツールを、消さずにここへ移してあります。
**ふだんの対戦では使いません。** [Sync_LvK](../Sync_LvK/) の画面つき版を使ってください。

消していないのは、当時どう作っていたかの記録として残しておきたいのと、
別の用途で使えるかもしれないためです。

---

## `cli/` — 画面なしのコマンド版

`LvKSyncServer.exe` / `LvKSyncClient.exe` と、それを起動する `.cmd` の一式。

**プロトコルが古いので、画面つき版と混ぜないでください。**
入力の中継はできますが、あとから足した次のものを知りません。

| 足したもの | コマンド版の挙動 |
|---|---|
| 設定メニュー（Shift）の同期 | 素通し。誰か1人が開くとその1台だけ止まってずれる |
| キャラ選択のずれ検知 | 何も出ない |
| カーソル初期化（1キー）の配布 | 押した人の画面しか直らない |
| 全員がそろうまで入力を止める | 止めない |

**まずいのは、黙って動いてしまうこと**です。コマンド版のサーバーは
知らない種類のメッセージを捨てるだけなので、画面つきのクライアントを
つないでも「メニューが同期しない」ことに気づけません。

`scripts/` の中身:

| ファイル | 何だったか |
|---|---|
| `start_server.cmd` | コマンド版サーバーの起動。ファイアウォールの穴あけつき |
| `start_client_pN.cmd` | コマンド版クライアントの起動 |
| `localtest_pN.cmd` | 1台のPCでゲームを複数動かして試すためのもの。`--index` を使う |
| `start_games.cmd` | 動作テスト用にゲームを2つ起動する。参照先が古い |

`localtest_pN.cmd` の `--index`（このPCの何番目のゲームか）は、
画面つきクライアントの「起動する」機能で要らなくなりました。
`--slot`（プレイヤー番号）と紛らわしく、実際に取り違えて不具合を出しています。

## `SyncLvK/` — 旧：状態同期

入力ではなく**キャラクターの状態変数そのもの**を送る方式のツール。
4窓で同じ動きをさせるデモに使いました。

入力を配る方式（いまの `Sync_LvK`）のほうが、送る量も少なく、
ずれの直し方もはっきりしているので、置き換わりました。

いまも使えるのは、**ここで測った同期対象の変数の範囲**です。
`Sync_LvK` のずれ検知は、このときの実測をそのまま使っています。

---

## `VPad/` — 仮想ゲームパッド

ViGEmBus と直接 IOCTL で話して、Xbox360 互換のパッドをソフトだけで生やすツール。

**このゲームには効きません。** るねキャラvsカワイコチャンズ のパッド読み取りは
**winmm**（`joyGetPosEx` / `joyGetNumDevs` / `joyGetDevCapsW`）経由で、
VPad が生やすのは XInput のパッドだからです。

入力をゲームへ届ける手段としては、いまは変数に直接書く方式に落ち着きました。
ツール自体は他の用途には使えるので残してあります。

## 建て直したいとき

それぞれのフォルダの `build.cmd` を実行してください。
`cli/` は `Sync_LvK/src/Common.cs` を参照しているので、
そちらが動いていることが前提です。

# ホスト用（Server）

**対戦部屋を立てる人**が使うツールです。

みんなのキー入力を受け取って全員に配る、中継係のプログラムです。
**このPCではゲームを動かす必要はありません。**

---

## 初回だけやること

### `open_port.bat` を実行する

Windowsファイアウォールに「TCP 47801 番の受信を許可」を追加します。

管理者権限が必要ですが、**ダブルクリックすれば自動で昇格を求めてきます。**
「はい」を押してください。

```
 LvKSync サーバー用のポートを開放します
   プロトコル : TCP
   ポート     : 47801
   方向       : 受信 (inbound)

 開放しました。
```

### インターネット越しに対戦するなら、ルーターの設定も必要

`open_port.bat` が設定するのは**このPCのファイアウォールだけ**です。

家の外の人と繋ぐには、ルーターの管理画面で
**「TCP 47801 番をこのPCへ転送する」**設定（ポート転送 / ポート開放 / NAT変換）
を追加してください。設定方法は機種ごとに違います。

同じ家・同じ回線の中だけで遊ぶなら、ルーターの設定は不要です。

---

## 毎回やること

### `start_server.cmd` を実行する

起動すると、参加者に伝えるIPアドレスが表示されます。

```
 [OK] ファイアウォール : ポート 47801 は開放済みです

----------------------------------------------------------
  参加者に伝えるアドレス
----------------------------------------------------------

  [同じ家/同じ回線の人には この番号]
      192.168.1.20

  [インターネット越しの人には グローバルIP]
      https://www.cman.jp/network/support/go_access.cgi
```

この番号を参加者に伝えてください。参加者はこれをクライアントに入力します。

### 繋がるとこう表示されます

```
[接続] P1 <- 192.168.1.31:51234
[接続] P2 <- 192.168.1.45:52001

frame 1420   tx   60/s  P1:U.....  60/s  P2:...R..  60/s  P3:--  P4:--
```

- `P1:U.....` の6文字が各プレイヤーのボタン状態（`U D L R A B`、`.` は押していない）
- `--` はまだ誰も座っていない席
- 終了は `Ctrl+C`

---

## 遊び終わったら

### `close_port.bat` を実行する

開けたポートを閉じます。こちらも自動で管理者権限を求めます。

ルーターにポート転送を設定した場合は、そちらも戻すのを忘れずに。

---

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 参加者が繋がらない | まず `open_port.bat` を実行したか確認 |
| 家の中からは繋がるが外から繋がらない | ルーターのポート転送が未設定です |
| `待ち受けに失敗しました` | 47801番を他のソフトが使っています。ポート番号を変えてください |
| 参加者に伝えるIPがどれか分からない | `192.168.` や `10.` で始まるのが家の中用。外向きは上記サイトで確認 |

---

## ポート番号を変えたいとき

3つのファイルを揃えて書き換えてください。

| ファイル | 場所 |
|---|---|
| `open_port.bat` | `set PORT=47801` |
| `close_port.bat` | `set PORT=47801` |
| `start_server.cmd` | `set PORT=47801` |

参加者側も `Client\start_client_pN.cmd` の `set PORT=47801` を
同じ番号に変えてもらってください。

### なぜ 47801 なのか

標準で決まっている番号ではなく、こちらで選んだものです。

Windowsは外向きの通信に **49152番以降**を自動で使うため、待ち受けを
そこに置くとOSと取り合いになります。それより小さく、かつ他のソフトと
ぶつかりにくい空き番号として選びました。

## オプション（詳しい人向け）

```
LvKSyncServer.exe [オプション]

  --bind <ip>      待ち受けアドレス（既定 0.0.0.0 = すべて）
                   同じPC内だけで試すなら 127.0.0.1 にするとFW警告が出ない
  --port <n>       ポート（既定 47801）
  --hz <n>         中継の周期（既定 60）
  --players <n>    最大人数 1-4（既定 4）
  --config <path>  設定ファイル（既定 LvKSyncServer.ini）
  --verbose        詳細ログ
```

設定ファイルは初回起動時に自動生成されます。
コマンドライン引数のほうが設定ファイルより優先されます。

---

## 通信量

1フレーム（1/60秒）につき1回、13バイト。
4人フルで繋いでも **毎秒1キロバイト未満**です。回線負荷はほぼゼロ。

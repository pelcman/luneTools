# LvKSync Server（サーバー側）

キー入力を中継するだけのサーバー。**ゲームには一切触らない**ので、
ゲームが入っていないPCやVPSでも動く。

## ポート

| | |
|---|---|
| プロトコル | **TCP** |
| ポート番号 | **47801**（既定。変更可） |
| 方向 | 受信（inbound） |

**開放が必要なのはこのサーバーのPCだけ。** プレイヤー側は外向きの接続しか
しないので、何も開ける必要はない。

## 使い方

1. `open_port.bat` — ファイアウォールに受信許可を追加（管理者権限。自動で昇格する）
2. `start_server.cmd` — サーバーを起動
3. 遊び終わったら `close_port.bat` — 受信許可を削除

### インターネット越しに対戦する場合

`open_port.bat` が設定するのは **Windows ファイアウォールだけ**。
ルーター側にも **TCP 47801 をこのPCへ転送する設定**（ポート転送 / NAT）が必要。

LAN内だけで遊ぶならルーターの設定は不要。

## ポート番号を変える

3ファイルすべてを揃えて書き換える。

- `open_port.bat` の `set PORT=47801`
- `close_port.bat` の `set PORT=47801`
- `start_server.cmd` の起動オプションに `--port <番号>` を追加

クライアント側も同じ番号を `--port` で指定すること。

## オプション

```
LvKSyncServer.exe [オプション]

  --bind <ip>      待ち受けアドレス（既定 0.0.0.0）
                   同一PC内だけなら 127.0.0.1 にするとFW警告が出ない
  --port <n>       ポート（既定 47801）
  --hz <n>         ブロードキャスト周期（既定 60）
  --players <n>    最大人数 1-4（既定 4）
  --config <path>  設定ファイル（既定 LvKSyncServer.ini）
  --verbose        詳細ログ
```

設定ファイルは初回起動時に自動生成される。コマンドライン引数のほうが優先。

## 表示の見方

```
frame 14094   tx   60/s  P1:U.....  54/s  P2:...R..  54/s  P3:--  P4:--
```

`U D L R A B` の6文字が各プレイヤーのボタン状態（`.` は離している）。
`--` は未接続。

## 帯域

1フレーム（1/60秒）につき1パケット、1パケット13バイト。
4人フルでも **1kB/s 未満**。

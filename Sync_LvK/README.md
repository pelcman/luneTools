# Sync_LvK — オンライン対戦ツール

**遊び方は [HOWtoUSE.md](HOWtoUSE.md) にまとめてあります。** まずそちらを読んでください。

## 何が入っているか

| | |
|---|---|
| `Server/bin/LvKSyncServerGui.exe` | **対戦部屋を立てる人**が使う。入力を配る中継係 |
| `Client/bin/LvKSyncClientGui.exe` | **参加する人**が使う。ゲームとサーバーをつなぐ |
| `Server/open_port.bat` `close_port.bat` | ホストのファイアウォールに穴をあける／閉じる |
| `src/` | ソース。`build.cmd` で建て直せる |

サーバーはゲームには一切触りません。ホストのPCでゲームを動かす必要もありません。
ポートは **TCP 47801 の1つだけ**で、開放が必要なのはホストのPCだけです。

## ざっくりの流れ

```
ホスト    open_port.bat  →  LvKSyncServerGui.exe で「開始」  →  IPを全員に伝える
参加者    LvKSyncClientGui.exe  →  名前・IP・自分の番号を入れて「接続」
```

全員つながるまで、誰のキーもゲームには届きません（わざとそうしています）。
そろうと動き出します。

ゲームは **パッチ済みのもの**（`game/LvK_online/`）を使ってください。
パッチの当て方は [LvKPatch](../LvKPatch/) を見てください。

## しくみ

入力は**ゲーム自身のフレーム番号**で配ります。実時間は一切使いません。

```
クライアント  V[654] が1つ進むごとに、自分の入力を「フレーム N 宛」として送る
サーバー      フレーム番号を付けたまま全員へ回す
クライアント  ゲームがそのフレームに来たら当てる
```

キャラ選択と設定メニュー（Shift）も同期します。キャラ選択が揃っているかは
サーバーとクライドの両方に出ます。ずれたら誰か1人が `1` を押せば全員直ります。

くわしい経緯と実測値は、リポジトリ直上の開発メモにあります。

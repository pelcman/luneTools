# るねキャラ vs カワイコチャンズ をオンラインで遊ぶ

このフォルダのツールを使うと、離れた場所にいる人どうしで対戦できます。最大4人まで。

ゲーム本体は `game/LvK_net/` に**パッチ済みのものを同梱**しています
（作者の許諾を得たもの）。これを使うなら手順①は飛ばせます。

> ### 先に読んでください
> **パッチ済みのゲームは、同期クライアントを動かしていないと
> キャラ選択から先でキーがまったく効きません。**
> 入力が全部ネットワーク経由になるためで、故障ではありません。
>
> ひとりで遊ぶときは、パッチを当てていない元のゲームを使ってください。
> `LvKPatch` は既定で**コピーを作って**当てるので、元のフォルダは残ります。

---

## 全体の流れ

```
   [サーバー役の人]                    [プレイヤー(1〜4人)]

   ポートを開ける                       ゲームにパッチを当てる (同梱版なら不要)
        ↓                                      ↓
   LvKSyncServerGui を起動              ゲームを起動
        ↓                                      ↓
   IPアドレスを参加者に伝える  ────→   LvKSyncClientGui で名前を入れて接続
        ↓                                      ↓
   誰が何Pか画面で確認                  「あなたは 2P です」と出る
                                               ↓
                                        全員そろったら対戦開始
```

サーバー役の人は、プレイヤーを兼ねてもかまいません。
サーバーはゲームには一切触りません。入力を配るだけです。

---

## 用意するもの

| 役割 | 必要なもの |
|---|---|
| サーバー役 | `Server` フォルダ / ポート **47801** を開けられる回線 |
| プレイヤー | ゲーム本体 / `Client` フォルダ（パッチはクライアントが当てます） |

`.NET Framework 4.x` が要ります。Windows 10 なら最初から入っています。

---

# 手順

## ① ゲームにパッチを当てる（ふつうは不要）

> **この手順は飛ばしてかまいません。**
> クライアントの「ゲーム」欄で `RPG_RT.exe` を指定しておけば、
> 接続するときに必要かどうかを調べて、その場で当ててくれます。
> ここは、あらかじめ手で当てておきたい人や、
> パッチ済みのコピーを別に作りたい人向けの説明です。

**これをやらないと同期しません。** 一度やれば次からは不要です。

パッチャーは既定で**パッチ済みのコピーを作ります**（`〜_online`）。
元のフォルダは触らないので、オフラインで遊ぶときはそちらを使えます。

ゲームは毎フレーム自分でキーボードを読み直してしまうので、そのままでは
外から入力を渡しても上書きされてしまいます。パッチは、その読み取りを
「ネットワークから届いた入力を読む」に差し替えます。

1. `LvKPatch\bin\LvKPatch.exe` を起動する
2. 「参照…」でゲームのフォルダ（`RPG_RT.exe` があるところ）を選ぶ
3. まず **「調べる」** を押す
   - `未パッチ 8 箇所` のように出れば対象のゲームです
4. 「コピーを作って当てる」にチェックが入っていることを確認する
   - 「作る先」に `〜_online` が入ります。変えてもかまいません
5. **「パッチを当てる」** を押す
   - `8 箇所にパッチを当てました。` と出れば完了

以降、**オンラインで遊ぶときは `〜_online` のほう**を起動してください。
元のフォルダはそのままなので、ひとりで遊ぶときはそちらを使います。

チェックを外すと元のフォルダを直接書き換えます。その場合でも
`RPG_RT.ldb.bak` が残るので「元に戻す」で戻せます。

---

## ② サーバーを立てる（サーバー役の人だけ）

### ポートを開ける

`Server\open_port.bat` を **右クリック → 管理者として実行**。
Windows のファイアウォールに **TCP 47801** の穴を開けます。

> ルーターを使っている場合は、ルーターの設定でも
> **TCP 47801 番をサーバー役のPCへ転送（ポートフォワード）** してください。
> ここが一番つまずきます。同じ家の中（同じWi-Fi）だけで遊ぶなら不要です。

遊び終わったら `Server\close_port.bat` を管理者として実行すると閉じられます。

### サーバーを起動する

`Server\bin\LvKSyncServerGui.exe` を起動して **「開始」** を押します。

```
待ち受け  0.0.0.0    ポート 47801   最大人数 4   [開始]
参加者に伝えるアドレス:  192.168.1.80    ポート 47801
```

「参加者に伝えるアドレス」に出た番号を参加者に教えてください。

- **同じ家の中**で遊ぶ → その `192.168.x.x` をそのまま伝える
- **インターネット越し**で遊ぶ → `whatismyip` などで調べた
  グローバルIPを伝える（ポートフォワードも必要）

接続すると一覧に出ます。

| プレイヤー | 名前 | アドレス | 入力 | 受信/秒 | 接続時刻 |
|---|---|---|---|---|---|
| 1P | るねつき | 192.168.1.80:56017 | `L..R..` | 60 | 21:03:11 |
| 2P | スギちゃん | 192.168.1.42:51220 | `..D..B` | 60 | 21:03:14 |
| 3P | 空き | | | | |
| 4P | 空き | | | | |

「入力」の `L U D R A B` は 左・上・下・右・Aボタン・Bボタンです。
押されている間だけ文字が出ます。ここが動いていれば入力は届いています。

その下の **「入力の様子」** で、誰が何を押しているかを絵で見られます。

```
      ■左 ■上 ■下 ■右 ■A ■B
1P るねつき   [十字と A/B]   ▁▂▁▃▁▁▂▃▁▁  ← 直近5秒の履歴 (左が古く、右が今)
2P スギちゃん [十字と A/B]   ▁▁▃▂▁▂▁▁▃▁
```

左が「いま押しているボタン」、右が履歴です。押しっぱなしは横に伸びた線として
残るので、入力が途切れていないか、誰の操作が届いていないかが一目で分かります。

## ③ プレイヤーがつなぐ

### クライアントを起動する

`Client\bin\LvKSyncClientGui.exe` を起動します。
**ゲームは先に起動しなくてかまいません。クライアントが面倒を見ます。**

```
名前 [ るねつき   ]  サーバー [ 192.168.1.80 ]  ポート [ 47801 ]
ゲーム [ C:\Games\LvK\RPG_RT.exe        ] [参照…] ☑起動する
プレイヤー番号 [ おまかせ ▼]  入力遅延 [ 2 ]フレーム  □詳細設定  [接続]
```

- **名前** … サーバーの一覧に出ます。誰が何Pか分かるようにするためのものです
- **ゲーム** … 「参照…」で `RPG_RT.exe` を選びます。一度選べば次から覚えています
- **起動する** … 接続するときにクライアントがゲームを起動します
- **サーバー** … サーバー役の人に教えてもらったアドレス
- **プレイヤー番号** … 何Pで遊びたいか。`おまかせ` なら空いている番号に入ります
- **入力遅延** … 後述。まずは `2` のままで

「接続」を押すと、クライアントがこの順に面倒を見ます。

1. そのゲームにパッチが当たっているか調べる
2. 当たっていなければ「いま入れますか」と聞く（`RPG_RT.ldb.bak` に退避）
3. ゲームを起動して、そのプロセスを掴む
4. サーバーへ接続する

**「接続」** を押すと、

```
あなたは 2P です
送信 60/秒   受信 60/秒   往復 8ms (推奨遅延 1f)   ゲーム pid 13144
```

と出ます。ここまで出れば準備完了です。

設定は自動で保存されるので、次回からは「接続」を押すだけです。

### キャラ選択まで進める

接続したら、**まだ「準備完了」は押さずに** ゲームを進めてください。

```
タイトル → ↓ → Enter → SinglePlayer / Multi_Player が出る
        → ↓ → Enter → Multi_Player → キャラ選択
```

このあいだ、**キー操作はネットワークに流れません**。
ほかの人がまだタイトルにいても、互いに邪魔しません。

タイトルのメニューは、パッチとは別の経路で動いているので普通に操作できます。
キャラ選択のカーソルは**準備完了を押すまで動きません**。これは意図した動きです。
全員がカーソルを同じ位置 (左上) に置いたまま待つためで、
ここが揃っていないと別のキャラで試合が始まってしまいます。

### 全員がキャラ選択に着いたら「準備完了」

全員がキャラ選択の画面に来たら、それぞれが **「準備完了」** を押します。

```
あなたは 1P です ― 準備できたら「準備完了」を押してください   ← まだ
あなたは 1P です ― ほかの人を待っています                     ← 自分は押した
あなたは 1P です ― 全員そろいました                           ← ここから同期
```

全員が押した瞬間から、操作が全員へ届くようになります。
サーバー画面の「準備」の列でも誰が押したか分かります。

ここから先は、**誰が操作しても全員の画面が一緒に動きます**。
キャラも一緒に選ぶことになるので、ずれる余地がありません。

あとは普通に遊ぶだけです。

## 操作キー

キーはプレイヤー番号ごとに決まっています。
クライアントは接続した番号に合わせて自動で切り替えます。

| | 左 | 上 | 下 | 右 | A | B |
|---|---|---|---|---|---|---|
| **1P** | ← | ↑ | ↓ | → | `Z` | `X` |
| **2P** | `E` | `W` | `R` | `Q` | `T` | `Y` |
| **3P** | `D` | `S` | `F` | `A` | `G` | `H` |
| **4P** | `O` | `I` | `P` | `U` | `J` | `K` |

自分が 2P なら `Q W E R T Y` を使います。
変えたいときは「詳細設定」→「操作キー」→「手動で入力」。

> クライアントはキーボードを直接見ています。ゲームの窓を選んでいなくても
> 入力は届きます。ただし他のソフトを操作している間もキーを拾うので、
> 遊んでいる間は文字入力などをしないでください。

## 入力遅延の決め方

回線には往復の時間がかかります。その間ずれないように、
入力をわざと少し遅らせてから全員で同時に反映します。

クライアントに **推奨遅延** が出ます。

```
往復 8ms (推奨遅延 1f)   ←  入力遅延を 1 にする
往復 60ms (推奨遅延 3f)  ←  入力遅延を 3 にする
```

- 小さいほど操作は軽いが、回線が揺れるとカクつく
- 大きいほど安定するが、ボタンの反応が鈍くなる
- 迷ったら推奨値 +1

接続したままでも変えられます。**全員で同じ値にしてください。**

参考値：同じ家の中で `1〜2`、インターネット越しなら推奨値に従ってください。

> ここで決めるのは下限です。実際の先読み量は、みんなの進み具合を見て
> クライアントが自動で足します。誰かのゲームが少し遅れても、
> その人が自動的に先まで送るので取りこぼしません。

## 同期できているかの確認

サーバー画面の右上に出ます。

```
同期: 一致 (1240回 確認)          ← 問題なし
同期: frame 8550 でずれました      ← 食い違った
```

各プレイヤーのゲームからキャラの状態をまとめた値を送ってもらい、
サーバーが同じフレームどうしで突き合わせています。
**別のPCで動いていても分かります。**

ずれたときは「ログの詳しさ」を **全部** にしてログを見てください。
どの変数のあたりで分かれたかまで残ります。

## うまくいかないとき

**「接続できませんでした」と出る**
- サーバー側で「開始」を押しているか
- IPアドレスの打ち間違い
- `open_port.bat` を管理者として実行したか
- インターネット越しならルーターのポートフォワード（TCP 47801）

**「ゲームの起動を待っています」から進まない**
- 「ゲーム」欄で `RPG_RT.exe` を指定して「起動する」にチェックを入れてください。
  クライアントが自分で起動して掴むので、この状態になりません
- 手で起動したゲームを使う場合は、「詳細設定」→
  「このPCの何番目のゲームか」が `0` になっているか確認してください。
  ここが `1` だと、2つ目のゲームが立ち上がるまで永久に待ちます

**キャラ選択でキーがまったく効かない（クライアントを動かしていない）**
- パッチ済みのビルドは入力が全部ネットワーク経由です。
  同期クライアントを起動して接続してください
- ひとりで遊びたいだけなら、パッチを当てていない元のフォルダを起動してください

**接続はできたのにキャラが動かない**
- ゲームにパッチを当てましたか（① をやり直す）
- クライアント下部の `ゲームのメモリ V[9001..9024]` を見てください
  - ここが押したとおりに `000100` などに変われば、入力は届いています
  - 変わるのにキャラが動かない → パッチが当たっていません
  - 変わらない → キー割り当てかサーバー接続の問題です
- 「詳細設定」の「入力ブロックの先頭」と、パッチを当てたときの値
  （既定 `9001`）が一致しているか

**他のプレイヤーだけ動かない**
- その人がパッチを当てていない、または接続していない
- サーバーの一覧でその番号に名前が入っているか確認してください

**同じPCで複数のゲームを動かすと止まる**
- 窓を選んでいないゲームが止まる場合、ゲーム側の設定が要ります。
  作者配布の最新版には入っています。

## いまできること / まだのこと

実際に動かして確かめたこと：

- **2人で6分間 (21181フレーム) 殴り合い続けて、状態の食い違い 0 件。**
  位置・体力・エフェクトがすべて一致した
- 入力がネットワーク越しに届き、ゲームのメモリに入ること
- パッチを当てたゲームが、その入力だけで操作できること
  （ゲームの窓を選んでいない＝キーボードが直接届かない状態で確認）
- 同じ家の中の2台で、毎秒60回の送受信・往復5msで安定すること
- 乱数は問題にならないこと。無操作で60秒ずれず、技を出したときのずれも
  すべて入力の取りこぼしが原因だった

まだできていないこと：

- 4人での確認（2人でしか試していません）
- 試合を決着まで通した確認（同期は保つが、自動操作では相手を倒せていない）
- キャラ選択や設定（ライフ・カブ・チーム・ステージ）を全員で揃える仕組み
  いまは **全員が同じ操作で同じキャラを選ぶ** 必要があります
- ピクチャ503（デバフの残り時間）の同期

## ログ

サーバーもプレイヤーも `bin\logs\` に日時つきで残します。
画面の「ログを開く」で開けます。

| 詳しさ | 出るもの |
|---|---|
| 標準 | 接続・切断・開始・停止 |
| 詳しい | ＋ 誰がどのボタンを押したか |
| 全部 | ＋ 配信の遅れ、送信にかかった時間、入力の途切れ、毎秒の状態 |

## コマンドから使いたい人へ

画面なしの版も同じフォルダに入っています。

> **注意**: 画面なしの版は古い方式のままです。フレーム単位の同期には
> 対応していないので、**対戦には画面つきの版を使ってください**。
> 画面なしの版は接続確認などの用途に残してあります。

```
Server\bin\LvKSyncServer.exe --bind 0.0.0.0 --port 47801 --players 4
Client\bin\LvKSyncClient.exe --host 192.168.1.80 --name るねつき --slot 2 --delay 2
```

画面つきの版も引数を受け取ります（`--start` を付けるとそのまま開始）。

```
LvKSyncServerGui.exe --start --bind 0.0.0.0 --port 47801 --players 4
LvKSyncClientGui.exe --start --name るねつき --host 192.168.1.80 --slot 2 --delay 2
LvKPatch.exe --folder "C:\Games\LvK" --apply
```

`--help` で一覧が出ます。

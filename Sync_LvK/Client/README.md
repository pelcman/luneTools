# Client — 対戦に参加する人へ

**遊び方は [../HOWtoUSE.md](../HOWtoUSE.md) にまとめてあります。** そちらを読んでください。

## 使うもの

```
bin\LvKSyncClientGui.exe
```

これ1つです。名前・ホストのIP・自分のプレイヤー番号を入れて「接続」を押します。

ゲームはこのツールに起動させることもできます。「ゲーム」の欄に
`game\LvK_online\RPG_RT.exe` のパスを入れて「起動する」にチェックしてください。
パッチが当たっていないゲームを選ぶと、その場で当てるか聞いてくれます。

## 操作キー

プレイヤー番号ごとに決まっています。接続した番号に合わせて自動で切り替わります。

| | 左 | 上 | 下 | 右 | A | B |
|---|---|---|---|---|---|---|
| **1P** | `←` | `↑` | `↓` | `→` | `Z` | `X` |
| **2P** | `E` | `W` | `R` | `Q` | `T` | `Y` |
| **3P** | `D` | `S` | `F` | `A` | `G` | `H` |
| **4P** | `O` | `I` | `P` | `U` | `J` | `K` |

これに加えて、番号によらず共通のものが2つあります。

| キー | 何が起きるか |
|---|---|
| `Shift` | キャラ選択で設定メニューを開く／閉じる（効くのは 1P だけ） |
| `1` | キャラ選択で**全員の**カーソルを初期化する（誰が押しても効く） |

## 画面の見かた

上のほうに、いま何をしているかが1行で出ます。

```
全員がそろうのを待っています (1/2)
キャラ選択中   ●  キャラ選択は揃っています
キャラ選択中   ×  キャラ選択がずれています   1 キーで全員のカーソルを初期化できます
試合中  frame=1234
```

その下に、届いている入力が絵で出ます。自分の行だけ動いて相手の行が止まって
いれば、相手から届いていません。逆に自分の行が動かなければ、
キー割り当てが自分のプレイヤー番号とずれています。

設定は自動で保存されるので、次回からは「接続」を押すだけです。

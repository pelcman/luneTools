# プレイヤー用（Client）

対戦に参加する人が使うツールです。**ゲームと同じPCで動かします。**

---

## 準備するもの

- ゲーム本体（`RPG_RT.exe`）
- サーバーのIPアドレス（ホストの人に聞いてください）

**ポート開放は要りません。** こちらから接続しにいくだけなので、
ファイアウォールもルーターも触らなくて大丈夫です。

---

## 手順

### 1. ゲームを起動する

タイトル画面のままで構いません。**キャラクター選択より前に起動しておくのが
おすすめ**です。

キャラクター選択でお互いのカーソルを合わせる必要があるため、
**全員が選び始める前に接続を済ませておいてください。**

### 2. 自分のプレイヤー番号のファイルを実行する

| あなたの番号 | 実行するファイル |
|---|---|
| 1P | `start_client_p1.cmd` |
| 2P | `start_client_p2.cmd` |
| 3P | `start_client_p3.cmd` |
| 4P | `start_client_p4.cmd` |

### 3. サーバーのIPを入力して Enter

```
サーバーのIPを入力して Enter (自分のPCなら空Enter):
```

ホストから聞いた番号（例 `192.168.1.20`）を入力します。
自分のPCでサーバーも動かしているなら、何も入れずに Enter。

### 4. こう表示されれば成功

```
対象プロセス: pid=12345 (index=0)
変数配列ベース: 0x1A2B3C4D5E0  (sentinel)
参加しました: あなたは 2P です (最大 4 人)

frame 1420   tx  60/s rx  60/s   1:U.....  *2:...R..  3:------  4:------
```

最後の行が流れ続けていれば繋がっています。

## 操作キー

ゲーム本体の割り当てと同じです。

| | 移動 | ボタンA | ボタンB |
|---|---|---|---|
| **1P** | `←` `↑` `↓` `→` | `Z` | `X` |
| **2P** | `Q` `W` `E` `R` | `T` | `Y` |
| **3P** | `A` `S` `D` `F` | `G` | `H` |
| **4P** | `U` `I` `O` `P` | `J` | `K` |

---

## 入力遅延の設定（回線が遠いとき）

相手の入力を**わざと少し遅らせて**適用する仕組みが入っています。
回線のゆらぎを吸収して、カクつきを減らすためのものです。

### 目安

| 相手との距離 | 設定値 |
|---|---|
| 同じ家（LAN） | `0` 〜 `2` |
| 国内 | `3` 〜 `5` |
| 遠距離・不安定 | `6` 以上 |

クライアントの表示に **推奨値が出ます**。

```
frame 1420   tx  60/s rx  60/s  RTT  48ms(推奨2f)   1:U.....  *2:...R..
                                ~~~~~~~~~~~~~~~~
```

`RTT` が往復時間、`推奨Nf` がその回線に見合った遅延フレーム数です。

### 変え方

`start_client_pN.cmd` の起動行に `--delay 4` のように足すか、
`bin\LvKSyncClient.ini` の `delay = 2` を書き換えてください。

**大きくすると安定しますが、その分ボタンを押してから反応するまでが遅くなります。**
小さすぎると相手の動きが飛びます。RTTを見ながら詰めてください。

### 実測値

| 設定 | 押してから反映されるまで |
|---|---|
| `--delay 0` | 31 ms |
| `--delay 6` | 131 ms |
| `--delay 20` | 355 ms |

設定した分だけきれいに増えます（1フレーム = 約16.7ms）。

## 画面の見方

```
frame 1420   tx  60/s rx  60/s   1:U.....  *2:...R..  3:------  4:------
      ~~~~       ~~~~~   ~~~~~    ~~~~~~~~  ~~~~~~~~~  ~~~~~~~~
      (1)        (2)     (3)        (4)       (5)        (6)
```

1. ゲーム内の経過フレーム
2. 自分の入力を送っている回数（毎秒）。**60前後が正常**
3. みんなの入力を受け取っている回数（毎秒）。**60前後が正常**
4. 1Pのボタン状態。`U D L R A B` の6文字（`.` は押していない）
5. `*` が付いているのが自分
6. `------` は誰も繋いでいない席

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| `RPG_RT を待っています....` から進まない | ゲームが起動していません。先にゲームを起動してください |
| `ゲームのデータを探しています…` から進まない | ゲームが応答していないか、別バージョンのランタイムです |
| `接続しています .......` のまま繋がらない | IPが違うか、サーバーが起動していません。ホストに確認してください |
| `サーバーが満員です` | すでに4人埋まっています |
| `OpenProcess に失敗しました` | 右クリック →「管理者として実行」で試してください |
| `ゲームが終了しました` と出て止まった | ゲームを再起動したらツールも起動し直してください |

## いま動くこと・動かないこと

**動くこと**

- 自分の入力がサーバーへ届く
- 他の人の入力が自分のPCのゲームのメモリに書き込まれる

**まだ動かないこと**

- **キャラクターは相手の操作で動きません。**

ゲーム側にネットワーク入力を読み取る処理を入れてもらう必要があり、
それがまだ入っていません。いまはツール側の通信だけが完成した状態です。

## おまけ : SyncLvK.exe（状態同期版）

`bin\SyncLvK.exe` は**別方式**のツールです。入力ではなくキャラクターの
状態そのものを丸ごとコピーするので、**ゲーム側の改造なしで今すぐ動きます。**

片方のゲームの動きを、もう片方のゲームがそのまま真似します。
デモや動作確認用です。

```
受ける側   SyncLvK.exe --role follower --listen
送る側     SyncLvK.exe --role leader --host 相手のIP
```

詳しくは `SyncLvK.exe --help`。

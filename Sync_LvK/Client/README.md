# LvKSync Client（プレイヤー側）

**ゲームと同じPCで動かす。** 自分の入力をサーバーへ送り、他プレイヤーの入力を
ゲームのメモリへ書き込む。

## ポート開放は不要

外向きの接続しかしないので、ファイアウォールの設定は要らない。
開放が必要なのはサーバー側のPCだけ。

## 使い方

1. ゲームを起動して**対戦画面まで進める**
   （変数配列は対戦中でないと特定できないため）
2. 自分のプレイヤー番号の `start_client_pN.cmd` を実行
3. サーバーのIPを聞かれるので入力（未入力なら `127.0.0.1`）

ツールはゲームと変数配列が見つかるまで待つので、先に起動しておいても構わない。

## キー割り当て

ゲーム本体の割り当てに合わせてある。

```
1P  ← ↑ ↓ →  + Z X
2P  Q W E R   + T Y
3P  A S D F   + G H
4P  U I O P   + J K
```

各クラスタの5番目がAボタン、6番目がBボタン。

## 同一PCで複数インスタンスを動かす場合

`start_games.cmd` でゲームを2つ起動できる（`LvK2` が無ければ自動で複製）。

このとき**ツクール側に以下の設定が必要**。無いとフォーカスを失った
インスタンスが完全に停止する。

```
ゲームのオプション設定 (03018) → Behavior when inactive = Run
```

別PC同士なら各自が自分の画面を前面に置くので不要。

## オプション

```
LvKSyncClient.exe [オプション]

  --host <ip>        サーバーのIP（既定 127.0.0.1）
  --port <n>         ポート（既定 47801）
  --slot <1-4>       希望するプレイヤー番号（0 = おまかせ）
  --netbase <n>      ネットワーク入力ブロックの先頭変数（既定 9001）
  --source <s>       ローカル入力の取得元  keys | netvar（既定 keys）
  --local-keys <s>   keys のときの割り当て 上,下,左,右,A,B
  --pid <n>          対象プロセスID（省略時は自動検出）
  --index <n>        RPG_RT が複数あるとき何番目か（起動が古い順）
  --no-write         受信しても書き込まない（動作確認用）
  --list             起動中の RPG_RT を一覧表示
```

## 同梱の SyncLvK.exe（状態同期版）

入力ではなくキャラクターの状態変数をそのまま複製する別方式のツール。
**ツクール側の改造なしで今すぐ動く**ので、挙動確認やデモに使う。

```
SyncLvK.exe --role leader   --host 127.0.0.1   （送る側）
SyncLvK.exe --role follower --listen           （受ける側）
```

詳しくは `SyncLvK.exe --help`。
